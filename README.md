# Функциональность обращений в личном кабинете лизингополучателя

Публичное аналитическое описание фичи по четырём направлениям обращений: реструктуризация, заказ справки о задолженности, страховые случаи и вопросы, связанные с повышением НДС до 22%.

> **NDA:** репозиторий не содержит наименования компании, внутренних систем, API-адресов, клиентских данных, коммерческих условий и закрытых регламентов.

## Структура документации

Документация организована строго по четырём разделам:

1. [Требования](docs/04-analysis-template.md#1-требования)
2. [Архитектура](docs/04-analysis-template.md#2-архитектура)
3. [База данных](docs/04-analysis-template.md#3-база-данных)
4. [Интеграции](docs/04-analysis-template.md#4-интеграции)

В документ добавлены Mermaid-диаграммы пользовательского потока, концептуальной архитектуры, логической модели данных (ERD) и последовательности взаимодействия.

## Принцип достоверности

Подтверждённые сведения отделены от концептуальных моделей и вопросов на уточнение. Архитектура, база данных и интеграции не выдаются за фактические решения: исходная техническая документация для них не предоставлена.
