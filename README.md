# Функциональность обращений в личном кабинете лизингополучателя

Публичное описание аналитического кейса по четырём направлениям обращений клиентов: реструктуризация, заказ справки о задолженности, страховые случаи и вопросы, связанные с повышением НДС до 22%.

> **Ограничение публичной версии:** репозиторий содержит только сведения, которыми можно безопасно поделиться в портфолио. Наименования компании, внутренних систем, API, клиентские данные, коммерческие условия и закрытые регламенты не публикуются.

## Контекст

Функциональность относится к личному кабинету лизингополучателя и охватывает четыре направления обращений:

1. Реструктуризация.
2. Заказ справки о задолженности.
3. Страховые случаи.
4. Изменение НДС — запросы на разъяснение и обращения с несогласием после повышения НДС до 22%.

## Принципы документирования

В документации разделяются:
- **Подтверждённая информация** — прямо сообщённые сведения о фиче.
- **Требует уточнения** — детали, которых пока нет в доступном описании.
- **Не предполагается автоматически** — поведение, которое нельзя выводить только из факта наличия категории обращения.

Документация не утверждает, что описанные обращения автоматически приводят к перерасчёту, изменению договора или графика платежей.

## Статус

Текущая версия фиксирует только сведения, уже известные из обсуждения. Это начальное описание функциональности, а не полная спецификация требований и не подтверждение реализации конкретных технических решений.
